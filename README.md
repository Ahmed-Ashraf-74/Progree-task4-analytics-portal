# 📊 VORTEXA - Enterprise Analytical Administration Portal

A multi-view business intelligence and analytics dashboard built with **React**, **Vite**, **Tailwind CSS**, **React Router**, and **Recharts** as part of the **Progree Remote Internship Program (Task 4)**.

🔗 **Live Demo:** [View Live Dashboard](https://progree-task4-analytics-portal.vercel.app)

---

## ✨ Key Features

- **Multi-View Client-Side Routing:** Seamless navigation across **Executive Overview**, **Revenue Analytics**, and **Enterprise Accounts Matrix** using `React Router`.
- **Reactive Data Visualization (Recharts):** Parses structured JSON profiles (`mockData.json`) into responsive **Area Charts**, **Operational Radar Charts**, **Product Mix Donut Charts**, and **Comparative Bar Charts**.
- **Client-Side Search & Multi-Column Sorting Matrix:** Real-time search filtering by organization/contact/region, status & tier dropdown filters, ascending/descending sorting across all 7 columns, and one-click **CSV Export**.
- **Dark / Light Theme State Engine:** Instant full-portal theme switching with persistent state in `localStorage` and dynamic chart axis/tooltip adaptation.

---

## 🛠️ Tech Stack

- **Framework:** React + Vite
- **Routing:** React Router DOM
- **Charts:** Recharts
- **Styling:** Tailwind CSS + Lucide Icons
